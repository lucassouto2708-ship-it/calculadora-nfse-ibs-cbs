# Calculadora NFS-e: ISSQN, CBS e IBS

Calculadora da AM Santos Assessoria Tributária para comparar o cálculo da NFS-e em 2026 (ano-teste, com PIS/COFINS) e a partir de 2027 (sem PIS/COFINS). Gera PDF do cálculo pelo botão "Gerar PDF do cálculo".

Página estática (HTML único), publicada via GitHub Pages.
